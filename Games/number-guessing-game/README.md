# Number Guessing Game

A resilient, terminal-based number guessing game where the player attempts to find a secret number generated by the computer[cite: 6, 8]. The game features dynamic visual feedback, multiple difficulty tiers, and strict input validation to prevent crashes[cite: 8, 9].

## Features

- **Difficulty Levels:** Players can choose from Easy (10 lives), Medium (7 lives), or Hard (4 lives) difficulty settings[cite: 8, 9].
- **Visual ASCII Feedback:** The game utilizes detailed ASCII art to provide directional hints, showing "Up" or "Down" arrows based on the player's guess[cite: 8, 9].
- **Robust Input Validation:** Implements comprehensive `try/except` logic and boundary checking to handle invalid alphanumeric inputs or out-of-range numbers gracefully[cite: 6, 8].
- **Modular Design:** The user interface components, menus, and ASCII graphics are isolated in a separate `UI_functions.py` module, keeping the core game loop clean[cite: 6, 9].
- **Cinematic Pacing:** Leverages the `time` module to create suspenseful loading animations and deliberate pauses between game states[cite: 6, 8].

## Usage

Ensure both `main.py` and `UI_functions.py` are in the same directory[cite: 6]. Run the game via your terminal:

```bash
python main.py
